EHLİYET: Yapay zekâ işlem ajanları için ehliyet sınavı, simüle sigorta ve Avalanche kaydı
OKX × Team1 Türkiye AI Agent Hackathon
Ehliyet riski ölçer, sigorta riski fiyatlar ve devralır.

PROJE KLASÖRÜ
  ~/Desktop/ehliyet/ehliyet   (çalışan proje: denetçi + web sitesi tek serviste)

CANLI TEST: CANLI-TEST.md dosyasını açın (adım adım, en sade hâliyle).

ÇALIŞTIRMA
  cd ehliyet
  npm install
  npm test          kurulum testi (internet ve anahtar gerekmez)
  npm run prova     çevrimdışı prova → http://localhost:4747
  npm start         gerçek OKX fiyatlarıyla → http://localhost:4747
                    (.env içine ANTHROPIC_API_KEY: hakem, kırmızı takım, Claude referans ajanı)
  npm run avalanche:setup   ehliyetleri Avalanche'a yazmak için (bir kez; ayrıntı CANLI-TEST.md)
  Windows: ehliyet/EHLIYET-DENETCI.cmd dosyasına çift tıklayın.

HIZLI BAKIŞ (sunucusuz)
  indir/ehliyet-site.html
    Sitenin kayıtlı kopyası. Çift tıklayıp tarayıcıda açın; salt okunurdur.
    İçinde dört referans denetim var, gerçek OKX fiyatlarıyla koşuldu:
      naif prova ajanı: ehliyet yok, poliçe reddedildi
      orta prova ajanı: A sınıfı, poliçe 199,60 $; poliçeli koşusunda çift emir 30 $ tazminat tetikledi
      dikkatli prova ajanı: B sınıfı, poliçe 150,58 $
    Yeniden üretmek için: cd ehliyet && npm run export -- --out ../indir/ehliyet-site.html
  indir/ehliyet-proje.zip
    Projenin ZIP'i (node_modules ve kayıtlar hariç).

KLASÖRLER
  ehliyet/                  Proje. Ayrıntılar: ehliyet/README.md
    public/                 Web sitesi, siyah tema (Sıralama, Sınav aç, Denetim, Sigorta, Sınavlar, Nasıl çalışır)

    src/chain/, contracts/  Avalanche kaydı: EhliyetRegistry sözleşmesi, kayıt ve doğrulama
    ENTEGRASYON.md          EHLİYET'i başka bir siteye gömmek
    CLAUDE.md               Claude Code için proje kuralları
